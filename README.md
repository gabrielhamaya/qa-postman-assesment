# Contact Us API tests: Restful Booker Platform

Automated API tests for the Contact Us form of https://automationintesting.online, built with Postman and run with Newman.

## Approach

I automated the contact form at API level because it's stable, fast, and independent of the UI. I chose it because it was the one area that worked during exploratory testing.

## Prerequisites and how to run

- Node 24 or later

```
npm install
npm test
```

The HTML report is written to `report/report.html`.
